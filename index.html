Deck Test Mail

Deck Test Mail は、開発者が自分のソフトウェアの動作を確かめるための内部の試験用の道具です。開発者が用意した試験用の Gmail アカウント 1 つだけを対象に、届いた試験用のメールを読み取り専用（gmail.readonly）で確かめます。

一般の方へは提供していません。開発者の試験用のアカウント以外のアカウントでは使いません。

Deck Test Mail is an internal testing tool. It reads test messages in a single test Gmail account owned by the developer, with read-only access. It is not offered to the public.
