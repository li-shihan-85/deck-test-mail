Deck Test Mail プライバシーポリシー

最終更新日: 2026 年 11 月 12 日

1. 対象

Deck Test Mail（以下「本ツール」）は、開発者が自分のソフトウェアの動作を確かめるための内部の試験用の道具です。対象は、開発者が用意した試験用の Gmail アカウント 1 つだけです。一般の方へは提供していません。

2. 取得する情報

本ツールは Google のアクセス許可「gmail.readonly」（読み取り専用）を使い、試験用のアカウントに届いた試験用のメールの件名・本文・送信日時を読み取ります。メールの送信・削除・変更はしません。

3. 使い道

読み取った情報は、開発者のソフトウェアが試験用のメールを正しく送れたかを確かめるためだけに使います。広告・分析・販売には使いません。

4. 保存と共有

読み取った情報は開発者の手元のコンピューターで扱い、第三者へ提供・共有しません。Google のユーザーデータの扱いは、Google API Services User Data Policy（限定使用の要件を含む）に従います。

5. アクセスの取り消し

本ツールへの許可は、Google アカウントの「サードパーティ製のアプリとサービス」（https://myaccount.google.com/connections）からいつでも取り消せます。

6. お問い合わせ

本ポリシーについてのお問い合わせは、このページを置いている GitHub のリポジトリの Issues からお寄せください。

Deck Test Mail is an internal testing tool that reads test messages in a single developer-owned test Gmail account with the read-only scope (gmail.readonly). Data is used only to verify the developer's own software, is processed on the developer's computer, and is not shared with third parties. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at https://myaccount.google.com/connections.
